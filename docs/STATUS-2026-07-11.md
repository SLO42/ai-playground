**Date:** 2026-07-11 · **Code:** branch `v2`, tip `757f34b` · **Docs:** branch `v2-main`

## 1. The Goal

One studio that takes any personal project from **idea → development → maintenance → published release**, fully automated, operated by a single person. Long-term it replaces the CLI workflow entirely. Feature-complete means every lifecycle stage runs hands-off, with the operator holding only the consent gates: real spend and publishing.
